# 温疫論（呉有性）原文・私評・現代語訳

明の呉有性（字は又可）『温疫論』（1642年）の原文を、篇ごとの小さな単位に分け、資料間の異同（校異）、注釈、秋吉質『温疫論私評』の評と細注、別本にある偶齋の注、日本語訳、解説を付けて、人にも機械にも読みやすい形にしたもの。

序跋6、上巻50篇、下巻36篇、付録10篇の全102単位について、句読点つきの原文、校異・注釈、注の原文、日本語訳（原文・注の訳と解説）がそろっている。英訳はない。

## 構成

```
00_序跋/    呉有性の自敘、四庫全書の提要、『温疫論私評』の序一・序二・凡例・跋
01_上巻/    原病〜乗除（50篇）
02_下巻/    雑気論〜諸家温疫正誤（36篇）
03_付録/    別本（溫疫論_1）だけにある篇：集補諸瘟方治（大頭瘟など8篇）、王恆齊先生瘟病論、附辨舌法
  index.md      篇の一覧
  NNN.md        原文（句読点つき）＋校異・校訂・注釈＋私評の注・偶齋の注（原文）
  NNN.ja.md     日本語訳：原文の訳・注の訳・解説
```

- 単位は1篇＝1単位。篇の中の段落は〔§1〕〔§2〕…と番号を付けた（底本の段落のまま。方名の行・薬の行も1段落）。
- 注の位置は〔§1の後〕〔§1「…昔以為」の後〕（直前の本文の字）の形で示した。篇名に付く注は〔篇名の注〕。

### 注の種類

| 印 | 内容 |
|---|---|
| 【質按】【質曰】 | 秋吉質『温疫論私評』の評（質按22段・質曰52段） |
| 【私評細注】 | 私評の本文の中の細注（出典・字義・地名など。私評本の分量の違いも含む） |
| 【偶齋】 | 別本（中醫笈成「溫疫論」溫疫論_1）にある偶齋の注（37か所） |

### ファイルの頭の情報（YAML）

| キー | 内容 |
|---|---|
| book | 底本の書名 |
| chapter / chapter_title | 篇の番号と名（0 序跋、1 上巻、2 下巻、3 付録） |
| unit | 単位の番号（ファイル名） |
| clause | 篇の中の番号 |
| paragraphs | 単位の中の段落の数 |
| formulas | 単位に載る方の名 |
| title | 篇名 |
| punctuated | 原文に句読点があるか |

訳のファイル（`.ja.md`）の頭には `unit` `clause` `lang` `source`（対応する原文のファイル）、方があれば `formulas` を付けている。

### 訳と解説の書き方

- 訳は直訳を基本とし、補った語は〔〕に入れた。他の資料と字句が大きく違うところは〔四庫全書本は「…」〕のように訳の中に記した。
- 注も、原文と同じ順に、同じ位置の印を付けて訳した。
- 解説は一般的な解釈を独自の言葉でまとめたもので、現代の注釈書からの引用はしていない。
- 『傷寒論』の条文を引くところは、宋本の条文番号を示した。
- 意味の取れない字句、字の確かでない人名などは、訳の〔〕と【注釈】に「わかっていること」と「わからないこと」を記した。
- 訳語と表記は、傷寒論・金匱要略などと同じ方針である。

## 底本と、本文の補い・訂正

### 底本

- **どのような本か**：呉有性『温疫論』の舊鈔本（中国國家圖書館所蔵）。自敘・上巻50篇・下巻36篇。『四庫全書』本が「補遺」に収める篇（正名・傷寒例正誤・諸家温疫正誤）や方（安神養血湯・太極丸）・疫痢兼証は、この本ではそれぞれの篇・位置にある。
- **どのように入手したか**：中醫笈成（jicheng.tw）が國家圖書館の画像によって公開している「溫疫論」の電子テキストを、中醫笈成のデータ（公有の典籍への編集は CC0）の HTML から、2026-11-15 に取得して使った。句読点は中醫笈成のもの。
- **字の変換**：旧字・異体字を日本の新字体に直した（方針は `字体と変換の方針.md`）。中醫笈成のこの本は「里」「谷」「系」「郁」「后」などを簡体字の形で入力しているので、用例をすべて確かめて「裏」「穀」「係」「鬱」「後」などに直した。また、一人称の「余」を「餘」に、「干」（おかす）を「幹」「乾」に作るところがあり、文脈と他の資料によって直した。どれも字体の直しとして扱い、校訂とはしていない。直したところには【注釈】を付けた。

### 序跋・注・付録の資料

- **四庫全書の提要**：Kanripo（漢籍リポジトリ）KR3e0087 の四庫全書（文淵閣）本。句読点はこのプロジェクトで付けた。
- **秋吉質『温疫論私評』**：中醫笈成「溫疫論私評」（皇漢醫學叢書第八冊、1936年刊の國家圖書館掃描本による）。序一（丹波元堅、1849年）・序二（筱崎弼、1848年）・凡例（阪本棟）・跋（玉木弘、1848年）と、評・細注。私評の「原序」は呉有性の自敘と同じ文なので、自敘の照合に使った。中醫笈成の私評は句点「。」だけなので、句読点を付け直した（字は変えていない）。中醫笈成の私評は「温疫初起」の篇が2回入っており、1回目は原病の評の一部が本文に混じった形なので、2回目を使った。
- **偶齋の注と付録**：中醫笈成のもう1つの「溫疫論」（行政院中醫藥委員會の文本による）。偶齋が誰かは、この本からはわからない。この本は入力の誤りが多く、「巳」を「已」「己」の意に使うところは直した。欠字の印は「□」で示した。

### 底本に足りないところ

- 底本の電子テキストに、欠けた丁や欠字は見つからなかった。

### 訂正（校訂）

- 本文の字は、入力の明らかな誤りのほかは改めていない。他の資料との違いは校異に記すだけにした。
- 中醫笈成の入力の空白1か所（下巻012）は除いた。

### 照合した資料

- **上巻・下巻・自敘**：Wikisource「溫疫論」、殆知閣「温疫论」、Kanripo KR3e0087（四庫全書本）、『温疫論私評』の本文（評の段を除く）、中醫笈成「溫疫論」の別本（溫疫論_1。偶齋の注は除く）。
- **付録**：殆知閣の周揚俊『温熱暑疫全書』巻四の疫病方論（大頭瘟〜軟腳瘟と、附採名方の一部が同じ文）。
- **校異**：これらの資料と底本の字句の違い（1,199件）。「X は「…」に作る」「…の間に、X は「…」がある」の形で、どの資料かを示す。字体だけの違い、句読点、（ ）の中の分量・割注、他の資料の欠落、資料の機械的な変換の跡（殆知閣・Wikisource の「濃朴」「病患」「快捷方式」など）や字形の似た字の入力の誤り（別本の「已→巳」「苓→芩」）は記していない。

## English summary

Structured edition of Wu Youxing's *Wenyi lun* (Treatise on Warm Epidemics, 1642), based on the old manuscript copy held by the National Library of China (digitized text from Zhongyi Jicheng). The text is divided into units by section: prefaces (6), volume 1 (50 sections), volume 2 (36 sections), and an appendix (10 sections found only in another edition). Each unit contains the punctuated classical text, textual variants and notes, the comments of the Japanese physician 秋吉質 (Akiyoshi; *Wenyi lun sihyō*, preface dated 1849), the notes of "Ouzhai" from another edition, and Japanese translations with explanatory notes. No English translation is included. Classical texts are in the public domain; new material is licensed under CC BY-SA 4.0. The translations were produced with an LLM and may contain errors; they are not medical advice.
